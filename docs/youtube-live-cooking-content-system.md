# BOSSA YouTube Live Cooking Content System

**Brand:** BOSSA Asado i Mar  
**Location:** Pietermaai, Curaçao  
**Theme:** Fire. Flavor. Sea.  
**Purpose:** Turn every BOSSA cooking session into a repeatable content and sales engine.

---

## 1. Core Strategy

When BOSSA goes live on YouTube, YouTube Studio should be used as the **publishing and control room**. The creative BOSSA style is built through the cooking, filming, clipping, editing, voiceover, thumbnails, and weekly publishing rhythm.

The goal is simple:

```text
Cook once → Go live → Clip → Edit → Post → Drive WhatsApp orders → Repeat every weekend
```

One live cooking session should create content for YouTube, Shorts, Instagram, TikTok, WhatsApp, hotel partners, and Airbnb/tourist campaigns.

## 3. Content Output From One Live

From one 30–60 minute live, create:

```markdown
1 long YouTube video: 8–15 minutes
3–5 YouTube Shorts
3 Instagram Reels
3 TikTok videos
1 WhatsApp promo clip
1 hotel/Airbnb promo clip
```

This turns one kitchen session into a full BOSSA content machine.

```markdown

- Adding tags
- Organizing playlists
```

## 11. Weekly Execution Checklist

### Before Live

- Confirm Fire Box ingredients
- Clean grill area
- Prepare lighting
- Charge phone/camera
- Test audio
- Prepare thumbnail image
- Prepare YouTube title
- Prepare WhatsApp order link

### During Live

- Show fire ignition
- Show meat close-ups
- Explain what is cooking
- Mention BOSSA location
- Mention Fire Box offer
- Capture plating moment
- Capture chef/customer reaction

### After Live

- Save replay
- Clip best fire shots
- Clip best meat shots
- Create 3 Shorts
- Create 3 Reels
- Create WhatsApp promo
- Upload long video
- Add CTA in description
- Share in WhatsApp broadcast
