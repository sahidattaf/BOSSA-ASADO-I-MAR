**Owner:** Sahid Attaf  
**Status:** Draft

## Purpose
Give BOSSA a weekend execution visual that shows what must happen before, during, and after the Weekend Fire campaign.

## Key message
Weekend Fire works when prep, content, WhatsApp, payment, pickup, and review happen in the right order.

## Diagram idea
Three-phase timeline:

1. Before weekend: menu, prices, photos, Stripe links, staff prep
2. During weekend: promote, confirm, cook, pack, pickup, solve issues
3. After weekend: review sales, learnings, photos, next offer

## Image prompt
Create a three-phase weekend execution map for BOSSA Asado i Mar. Show Friday prep, Saturday service, and Sunday review. Use fire-grill icons, WhatsApp confirmation, Stripe payment link, pickup bag, and KPI dashboard. Premium dark navy background with orange and teal accents.

## Canva prompt
Design a timeline infographic titled “BOSSA Weekend Execution Map.” Use three columns: Before, During, After. Each column has five checklist cards and icons.

## Suggested layout
- Header: Weekend Execution Map
- Three large columns
- Bottom: “Review every Sunday. Improve every weekend.”

## Where this visual will be used
- Notion weekly planning
- Staff prep checklist
- Weekend campaign dashboard
- Founder review
