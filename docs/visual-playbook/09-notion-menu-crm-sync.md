# 09 — Notion Menu & CRM Sync

**Owner:** Sahid Attaf  
**Status:** Draft  
**Last updated:** 2026-05-18

## Purpose
Show how BOSSA’s menu, prices, orders, guest leads, and campaign notes can eventually sync through a Notion control layer.

## Key message
Notion should become the BOSSA source of truth: menu items, prices, Stripe links, WhatsApp leads, order notes, and weekly performance.

## Diagram idea
Sync map with Notion at the center:

1. Website menu reads from structured menu data
2. WhatsApp captures order/contact intent
3. Stripe captures payment/deposit
4. Notion stores menu, orders, leads, and KPIs
5. Weekly review updates the next campaign

## Image prompt
Create a clean Notion sync diagram for BOSSA Asado i Mar. Put Notion in the center with connected nodes: Website Menu, WhatsApp Orders, Stripe Payments, Guest CRM, KPI Dashboard, Weekly Review. Use dark navy background, cream cards, fire-orange arrows, and teal sync lines.
