# BOSSA Asado i Mar — Visual Operating Playbook

**Owner:** Sahid Attaf  
**Status:** Draft  
**Last updated:** 2026-05-18

## 1. What this Visual Operating Playbook is

This playbook turns the BOSSA Asado i Mar restaurant system into visual diagrams, infographic prompts, carousel copy, Canva briefs, and image-based guide sections.

It is designed for founder clarity, staff onboarding, weekend campaign planning, investor explanation, partner conversations, and marketing execution.

## 2. Why it exists

BOSSA is not only a menu. It is a fire-grill operating system: food, flow, WhatsApp ordering, weekend boxes, visuals, content, payments, and customer experience.

This playbook makes that system visible so the team can build faster, explain better, and publish with consistency.

## 3. How it supports BOSSA Asado i Mar

- Clarifies the restaurant brand story
- Converts Weekend Fire into repeatable visuals
- Helps staff understand order flow and pickup flow
- Gives marketing clear visual prompts
- Supports future Stripe payment links and Notion control layers
- Creates reusable assets for website, Instagram, WhatsApp, flyers, investor decks, and eBook sections

## 4. The 8 visual frameworks

### 1. M-A-P — Master Architecture Picture
- **M:** Main vision
- **A:** Audience and assets
- **P:** Path from attention to order

### 2. P-I-L-L-A-R — Brand Pillar Map
- **P:** Product pillar
- **I:** Identity pillar
- **L:** Location pillar
- **L:** Loyalty pillar
- **A:** Atmosphere pillar
- **R:** Revenue pillar

### 3. F-L-O-W — Guest Journey Flow
- **F:** Find BOSSA
- **L:** Learn the offer
- **O:** Order or reserve
- **W:** Walk in / pick up / share

### 4. R-E-V-E-N-U-E — Revenue Engine Map
- **R:** Roast boxes
- **E:** Events and party orders
- **V:** Visual marketing
- **E:** Experience upsells
- **N:** Notion/order tracking
- **U:** Upsell drinks and sides
- **E:** Evaluate weekly

### 5. B-U-I-L-D — Asset Build System
- **B:** Brand story
- **U:** Use case
- **I:** Image prompt
- **L:** Layout
- **D:** Distribution

### 6. S-Y-N-C — Notion / Website / WhatsApp Sync
- **S:** Source of truth
- **Y:** Yield order data
- **N:** Notion tracking
- **C:** Customer confirmation

### 7. L-A-U-N-C-H — Weekend Campaign Launch
- **L:** List offer
- **A:** Assets ready
- **U:** Upload to site
- **N:** Notify WhatsApp/IG
- **C:** Confirm orders
- **H:** Harvest learnings

### 8. S-C-A-L-E — Growth Map
- **S:** Standardize
- **C:** Campaigns
- **A:** Automations
- **L:** Local partnerships
- **E:** Expand to rooftop/events
