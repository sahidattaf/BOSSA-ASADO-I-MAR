# 03 — Weekend Fire Pillars

**Owner:** Sahid Attaf  
**Status:** Draft  
**Last updated:** 2026-05-18

## Purpose
Turn the Weekend Fire concept into a clear visual pillar system for customers, staff, and marketing.

## Key message
Weekend Fire is built on numbered boxes, limited batches, fire-grill flavor, fast pickup, and repeatable content.

## Diagram idea
Five vertical pillars:

1. Box #1–#8 Menu
2. Fire & Sea Specials
3. WhatsApp Confirmation
4. Stripe Deposit Links
5. Pickup Flow

## Image prompt
Create a premium infographic titled “BOSSA Weekend Fire Pillars.” Show five fire-lit pillars standing near the sea at sunset. Each pillar has one label: Numbered Boxes, Fire & Sea Specials, WhatsApp Confirmation, Stripe Deposit Links, Pickup Flow. Use orange fire glow, teal ocean accents, dark premium background, and clean restaurant branding.

## Canva prompt
Design a vertical carousel slide with 5 pillar cards. Use BOSSA colors: fire orange, sea teal, cream text, dark navy background. Add small icons for box, seafood, WhatsApp, Stripe, and pickup bag.

## Suggested layout
- Top: Weekend Fire Pillars
- Middle: 5 pillar cards
- Bottom: “Order by number. Confirm by WhatsApp. Pickup fast.”

## Where this visual will be used
- Weekend Fire website section
- Instagram carousel
- WhatsApp broadcast
- Notion campaign page

## Next action
Create the carousel version first, then use it for the Weekend Fire & Sea launch post.
