# 05 — WhatsApp Order Flow

**Owner:** Sahid Attaf  
**Status:** Draft  
**Last updated:** 2026-05-18

## Purpose
Explain the customer order journey from seeing a BOSSA offer to confirming pickup through WhatsApp.

## Key message
WhatsApp is the fastest confirmation layer for BOSSA: customer chooses, sends details, BOSSA confirms capacity, customer picks up or reserves.

## Diagram idea
Linear flow:

1. Customer sees Weekend Fire offer
2. Customer taps WhatsApp button
3. Message opens with prefilled order template
4. Staff confirms availability and pickup time
5. Customer pays deposit or pays later
6. Order is prepared and handed off

## Image prompt
Create a clean WhatsApp order flow diagram for BOSSA Asado i Mar. Show six steps from Instagram/website offer to WhatsApp message, staff confirmation, payment/deposit, kitchen prep, and pickup. Use fire orange arrows, WhatsApp green accents, dark restaurant background, and simple icon cards.

## Canva prompt
Design a horizontal flowchart titled “How BOSSA WhatsApp Ordering Works.” Use six rounded cards with icons: offer, tap, message, confirm, pay, pickup.
