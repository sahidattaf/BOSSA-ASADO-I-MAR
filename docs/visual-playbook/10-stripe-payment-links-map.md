# 10 — Stripe Payment Links Map

**Owner:** Sahid Attaf  
**Status:** Draft  
**Last updated:** 2026-05-18

## Purpose
Document how Stripe Payment Links will support BOSSA deposits, Weekend Fire boxes, Fire & Sea Specials, and future preorder flow.

## Key message
Stripe should start simple: Payment Links for fixed offers and deposits before moving into custom checkout and automation.

## Diagram idea
Payment flow:

1. Guest selects box or special
2. Guest confirms on WhatsApp
3. Staff sends or website displays Stripe Payment Link
4. Guest pays deposit or full amount
5. BOSSA confirms pickup
6. Order is tracked in Notion

Use fire-orange, Stripe purple, WhatsApp green, Notion black/white, and premium restaurant styling.
