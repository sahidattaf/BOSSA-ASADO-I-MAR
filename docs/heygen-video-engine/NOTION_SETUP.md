# BOSSA Video Engine Notion Setup

Create this operating board under BOSSA Owner Dashboard v1.

## Database name
BOSSA Video Production Pipeline

## Properties
- Video Name: Title
- Status: Backlog, Brief Ready, Script Draft, Awaiting Approval, In Production, Quality Review, Scheduled, Published, Measured, Archived
- Objective: Reservations, Catering, Private Events, Tourist Awareness, Brand, Staff Training, Other
- Language: EN, PAP, NL, ES
- Channel: Instagram, TikTok, WhatsApp, Website, YouTube, Staff Training
- Format: 9:16, 1:1, 16:9
- Audience: Text
- Offer or Message: Text
- CTA: Text
- Destination: URL
- Owner: Person
- Approval Owner: Person
- Due Date: Date
- Publish Date: Date
- Script Version: Text
- Script Approved: Checkbox
- Language Approved: Checkbox
- Final Approved: Checkbox
- HeyGen Job ID: Text
- Draft Video URL: URL
- Published URL: URL
- Tracking ID: Text
- Views: Number
- Completion Rate: Number
- Clicks: Number
- Qualified Inquiries: Number
- Confirmed Bookings: Number
- Attributed Revenue: Number
- Learning: Text

## Views
1. Production Board grouped by Status.
2. Awaiting Approval filtered to Awaiting Approval and Quality Review.
3. Publishing Calendar using Publish Date.
4. Published Performance filtered to Published and Measured.
5. Revenue Campaigns filtered to Reservations, Catering, and Private Events.

## Governance
GitHub stores approved prompts and process versions. Notion stores execution status and performance. No public release occurs until Final Approved is checked. Never store API secrets in Notion or the public repository.
