# BOSSA HeyGen Video Engine

## Purpose
Turn BOSSA's offers, events, menu education, tourist experiences, staff training, and founder messages into repeatable multilingual avatar videos.

## System role
GitHub is the source of truth for prompts, SOPs, templates, automation contracts, and technical documentation.
Notion is the operating cockpit for campaign planning, approvals, production status, publishing, and performance tracking.

## Core workflow

Idea or campaign brief
→ Script generation
→ Human approval
→ HeyGen avatar production
→ Brand finishing
→ Publish
→ Capture metrics
→ Improve the next script

## Priority use cases

1. Weekend Fire Box promotions
2. Tourist welcome videos
3. Catering and private-event sales
4. Menu education
5. Staff training
6. AI Concierge explainers
7. Founder updates

## Operating rule
No video is generated until the offer, audience, CTA, language, and destination channel are defined.
No video is published without brand, factual, subtitle, and CTA checks.
