# BOSSA Video Publishing Checklist

## Asset
- Final approved file selected
- Correct aspect ratio
- Correct caption version
- Thumbnail or cover selected
- Subtitles enabled where supported

## Destination
- Primary CTA visible
- Link tested on mobile
- WhatsApp message prefill tested
- Reservation or landing page loads correctly
- Campaign tracking identifier included

## Publication
- Correct account and channel
- Publish date and time confirmed
- Location tag added when relevant
- Partner tags approved
- Publication URL recorded in Notion

## Follow-up
- Sales Operator notified for lead campaigns
- 24-hour metric review scheduled
- 7-day metric review scheduled
- Comments and inquiries assigned
